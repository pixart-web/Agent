# Kiko for macOS 0.3.4 — release candidate notes

**Status:** release candidate for **owner review** (internal, unsigned).
**Built:** 2026-11-23, branch `feat/kiko-modules-pt`.

## Changes since 0.3.3

- Every module screen is in European Portuguese: commands, tasks, projects, approvals,
  executions, reports, agents, automations, knowledge, CRM, marketing, email, calendar,
  integrations, Codex, notifications, settings, subscription and platform administration.
- Statuses, roles, risk levels, priorities, triggers and knowledge categories are shown in
  Portuguese (`lib/labels.ts`); dates use the Portuguese format.
- Still in English: messages generated by the server (notification titles such as "Approval
  required", project/task activity entries), the sign-in and account screens, and onboarding.
