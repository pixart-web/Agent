# Kiko for macOS 0.2.1 — release candidate notes

**Status:** release candidate for **owner acceptance testing** (internal, unsigned).
**Built:** 2026-11-20 from `caf7dd0` (clean tree), branch `qa/kiko-acceptance-hardening`.
Evidence: `docs/qa/KIKO-FULL-QA-REPORT.md` §26.

## Changes since 0.2.0

- **Fixed: Kiko stalled while behind other windows.** On macOS 27.2.1 the window's page was
  suspended after a few seconds in the background: native notifications stopped and a plan being
  generated by the local AI was not shown. The page is now throttled, not suspended.
- **Fixed: invited team members were stuck on "Set up your company workspace".** Accepting an
  invitation now opens the team's workspace directly.
- **Fixed: viewers (read-only role) could create and change items.** All writes are refused
  for viewers; the dashboard shows your workspace and role, and viewers see a read-only notice.
- Faster client (CRM contacts) list.

## Installation (internal testing)

Same as 0.2.0: start the backend (`scripts/local/kiko-local.sh start`, Ollama running with
`gemma4:12b-it-qat`), drag Kiko to Applications, open it with right-click → Open the first time.
The server connection stored by earlier versions is kept.
