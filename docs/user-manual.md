# User manual

## Getting started

Register, verify the address delivered by the configured mail provider, sign in, and complete the
workspace onboarding. Describe the organization and choose initial objectives. Kiko then opens the
command composer.

## Daily workflow

1. Open **Kiko AI** and state an outcome without including credentials or sensitive secrets.
2. Review the resulting command and Supervisor plan; refine it before approval.
3. Use **Tasks** or **Projects** to assign, schedule, transition, and inspect work history.
4. Resolve items in **Approvals**. The requester cannot approve their own high-risk action.
5. Review final results, evidence, activity, and notifications. Archive rather than delete work that
   may be required for audit.

CRM stores organizations, contacts, opportunities, projects, and activities. Marketing drafts
campaigns and content; Automations run only when enabled and always preserve run history. Knowledge
accepts bounded safe documents and supports grounded retrieval. Integrations display configuration
and reconciliation health; a configured credential is not proof that a provider journey passed.

Profile, password, notification preferences, sessions, workspace export, and workspace settings are
under **Settings**. Use **Team** for invitations if your role permits it. Sign out shared devices and
revoke unfamiliar sessions immediately.
