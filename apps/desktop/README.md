# Kiko desktop (macOS)

Tauri 2 shell around the Kiko web UI. Architecture, security model and decisions:
`docs/desktop/KIKO-MACOS-ARCHITECTURE.md`.

## Prerequisites

- macOS on Apple Silicon, Xcode Command Line Tools
- Rust stable (`rustup`), Node 22+, pnpm 11 (`corepack enable`)

## Common tasks

```bash
pnpm install                                   # from the repository root
pnpm --filter @agent/desktop run build:ui      # static export of apps/web into dist/
cd apps/desktop/src-tauri && cargo test        # Rust unit tests
cd apps/desktop && pnpm tauri build --debug --no-bundle   # debug binary
cd apps/desktop && CI=true pnpm tauri build    # release .app + .dmg (ad-hoc signed)
```

Run the debug binary against a local API:

```bash
KIKO_API_URL=http://127.0.0.1:8000 apps/desktop/src-tauri/target/debug/kiko-desktop
```

`KIKO_DESKTOP_EPHEMERAL_SESSION=1` keeps the session in memory instead of the Keychain.
`CI=true` makes the DMG step skip Finder window styling (needed in CI and in sessions without
Automation permission).

## E2E

`e2e/run-journey.sh` drives the real app (debug build) through registration → verification →
onboarding → governed work → relaunch → logout against a local API. See
`docs/desktop/KIKO-MACOS-TESTING.md`.

## Icon

`assets/icon-source.png` is a placeholder generated by `scripts/make-icon.py`. Replace it with
the Pixart brand mark and run `pnpm tauri icon assets/icon-source.png -o src-tauri/icons`.
